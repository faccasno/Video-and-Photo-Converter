# 🎬 Video and Photo Converter by FACCASNO

Простой конвертер видео и фото на Python.

---

## 🚀 Для обычных пользователей (просто запустить)

Тебе **не нужно** устанавливать Python, ничего компилировать или писать команды. Всё уже готово!

1.  Перейди на вкладку **Releases** (над списком файлов на GitHub, рядом с Code).
2.  Найди там архив с названием вроде `VideoConverter_v1.0_Ready.zip` (или просто `Release.zip`).
3.  Скачай и распакуй его в любую папку.
4.  Запусти файл **`main.exe`**.

> ⚠️ **Важно:** Рядом с `main.exe` обязательно должна лежать папка **`bin`**, а внутри неё — файл `ffmpeg.exe`. Если ты скачал только exe-шник без папки bin, программа не запустится. В нашем архиве они идут вместе.

## 📋 Инструкция по запуску (для разработчиков / чтобы запустить код)

Если ты хочешь запустить проект из исходного кода (`.py` файлы), изучить логику или дописать что-то своё:

1.  **Скачай проект** (нажми Code → Download ZIP или `git clone`).
2.  **Создай папку `bin`** в корне проекта.
3.  **Скачай FFmpeg** с сайта [gyan.dev](https://www.gyan.dev/ffmpeg/builds/) (выбирай сборку `ffmpeg-release-essentials.zip` — она легче).
4.  **Распакуй архив**. Внутри ты увидишь папку с названием вроде `ffmpeg-6.1-essentials_build`. Зайди в неё, потом в папку `bin`. Найди там файл `ffmpeg.exe` и скопируй **только этот один файл** в свою созданную папку `bin` (в корне твоего проекта).
    > ⚠️ Важно: В твоей папке `bin` должен лежать **только** файл `ffmpeg.exe`. Никаких лишних папок внутри быть не должно.
5.  **Установи зависимости**:
    ```bash
    pip install Pillow
    ```
6.  **Запусти программу**:
    ```bash
    python main.py
    ```

## 💾 Как собрать свой .exe (если хочешь сделать программу для друга)

1.  Установи PyInstaller: `pip install pyinstaller`.
2.  Выполни команду в терминале:
    ```bash
    python -m PyInstaller --onefile --noconsole --add-binary "bin/ffmpeg.exe;bin" main.py
    ```
3.  Готовый файл `main.exe` появится в папке `dist`.
